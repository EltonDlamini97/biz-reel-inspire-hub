# Biz Reel Inspire Hub

Prompt: All-in-One SMME, Movie & Daily Motivation Website

Role: Act as an expert full-stack developer, UI/UX designer, and AI integration specialist.

Objective: Build a modern, responsive website that combines an SMME business directory, movie showcase, and daily motivation platform into one user-friendly application.

Core Features:

SMME Showcase

Allow small businesses to register and create profiles.

Display products, services, contact details, and locations.

Include search, filters, enquiries, and featured businesses.

Movie Showcase

Display movies with posters, descriptions, genres, ratings, and trailers.

Include search, watchlists, recommendations, and legitimate streaming links.

Use the TMDB API for movie information.

Daily Motivation

Display daily inspirational quotes and success stories.

Allow users to share quotes and read motivational articles.

Include daily challenges and personal development content.

User Accounts & Admin Dashboard

Support visitors, registered users, business owners, editors, and administrators.

Enable business verification, content moderation, and platform management.

Design Requirements: Create a professional, mobile-friendly interface with a modern layout, cinematic movie sections, business-focused pages, and an uplifting motivational section.

Technical Requirements: Use React, TypeScript, Tailwind CSS, and Supabase for authentication and database management. Integrate the TMDB API, apply secure access controls, and ensure POPIA compliance.

Expected Output: Deliver a functional, scalable website with a unified homepage, business directory, movie catalogue, daily motivation section, user authentication, and admin dashboard. Build and test the features in phases, prioritising the core functionality first.
